HIGHLAND WHEELHOUSE: PICTURES FOR THE WEB

Every picture comes in two formats with the same name:
  .avif  smallest file, use it first
  .webp  backup for the few browsers without AVIF

desktop/  for screens wider than 768 px
phone/    for screens up to 768 px. Some are cut to a different shape to fit the phone layout.
The number in each name is the width in pixels, e.g. hero-forest-trail-780w = 780 px wide.
Pictures are about twice the size they are shown, so they stay sharp on retina screens,
except where the original photo was smaller (they were never enlarged).

How to use one picture in HTML (phone version, desktop version, then the backup):
  <picture>
    <source media="(max-width: 768px)" srcset="images/phone/hero-forest-trail-780w.avif" type="image/avif">
    <source media="(max-width: 768px)" srcset="images/phone/hero-forest-trail-780w.webp" type="image/webp">
    <source srcset="images/desktop/hero-forest-trail-1379w.avif" type="image/avif">
    <img src="images/desktop/hero-forest-trail-1379w.webp" alt="A rider on a forest trail below snowy mountains" width="1379" height="1034">
  </picture>
